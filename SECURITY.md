# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately. Do not create a public issue. Instead, email us at YOUR_EMAIL_HERE with a description of the vulnerability and steps to reproduce it if possible.

We will investigate the issue and respond as soon as possible. After the vulnerability is resolved, we will disclose the issue in the CHANGELOG or security advisory as appropriate.

## Supported Versions

We generally maintain only the latest release of the project. Security patches will only be applied to the most recent stable release. Please upgrade to the latest version to ensure you receive fixes.

## Responsible Disclosure

We appreciate your help in responsibly disclosing security issues. Please do not engage in any activity that could harm users or systems, such as exploiting a vulnerability to gain unauthorized access or leaking data.
